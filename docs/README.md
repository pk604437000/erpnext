# 项目文档入口

本目录存放本项目的实施、运维、本土化和二次开发资料。处理 ERPNext 业务配置、平台使用或开发问题时，优先参考以下官方文档，并结合本目录中的项目方案与实施计划。

## ERPNext 业务与操作文档

- [ERPNext 官方文档](https://docs.frappe.io/erpnext)：面向实施顾问、系统管理员和业务用户，涵盖采购、销售、库存、财务、生产、用户与权限等模块的配置和日常操作。
- [Getting Started with ERPNext](https://docs.frappe.io/erpnext/getting-started-with-erpnext)：适合项目启动和首次上线，介绍部署准备、公司信息、基础设置、用户培训及上线等步骤。

## Frappe Framework 开发文档

- [Frappe Framework 官方文档](https://docs.frappe.io/framework/user/en)：面向开发和技术运维人员。ERPNext 构建在 Frappe Framework 之上；进行中国大陆本土化、二次开发、应用或插件开发、自定义 DocType、前后端编码及 API 集成时，应以此文档为主要技术参考。

## 使用约定

- 业务流程、功能配置和平台操作问题，先查阅 ERPNext 官方文档。
- 框架机制、定制开发、接口集成和技术排障问题，先查阅 Frappe Framework 官方文档。
- 官方文档与项目实际版本存在差异时，以当前项目代码、已部署版本及本目录中的项目约定为准，并在项目文档中记录差异。
